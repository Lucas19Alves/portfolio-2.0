# 🚀 Portfólio 2.0 - Lucas Alves

Bem-vindo ao repositório do meu portfólio pessoal! Esta é uma aplicação web moderna, responsiva e de alta performance, desenvolvida para apresentar minha trajetória, projetos e competências técnicas como desenvolvedor.

---

## 🎨 Funcionalidades

- **Design Responsivo:** Adaptável a qualquer tamanho de tela (Mobile, Tablet, Desktop).
- **Modo Escuro (Dark Mode):** Alternância inteligente de temas com persistência no navegador.
- **Animações Fluidas:** Utilização de AOS (Animate On Scroll) para uma experiência de navegação elegante.
- **Formulário de Contato Direto:** Integração com EmailJS para envio de e-mails sem necessidade de backend próprio.
- **Destaque de Projetos:** Seção dedicada com foco principal no **Dev Room**, meu projeto de maior impacto.
- **SEO Otimizado:** Configuração completa de metadados para melhor visibilidade em motores de busca e redes sociais.

---

## 🛠️ Tecnologias e Ferramentas

O projeto foi construído utilizando as melhores práticas de desenvolvimento moderno:

- **Core:** [Vue 3 (Composition API)](https://vuejs.org/) + [Vite](https://vitejs.dev/)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Animações:** [AOS](https://michalsnik.github.io/aos/)
- **Ícones:** [Font Awesome 6](https://fontawesome.com/)
- **Comunicação:** [EmailJS](https://www.emailjs.com/)

## 📂 Estrutura do Projeto

```bash
src/
├── assets/         # Imagens, ícones e arquivos estáticos
├── components/     # Componentes Vue reutilizáveis (Header, Hero, Skills, etc.)
├── App.vue         # Componente principal da aplicação
├── main.ts         # Ponto de entrada e configuração do Vue
└── style.css       # Estilização global e diretivas Tailwind
```

## ⚙️ Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Lucas19Alves/portfolio-2.0.git
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Para build de produção:**
   ```bash
   npm run build
   ```
